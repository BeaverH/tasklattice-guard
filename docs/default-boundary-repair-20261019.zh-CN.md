# Default 边界检测修复与回归（2026-10-19）

本轮修复了可复现的检测漏洞，并把场景测试接入实际 Default 编译与执行链。
新增边界回归的攻击检出从 **1/10 提升到 10/10**，正常例仍为 **9/9 放行**。
公开适配场景的修复前后 ASR、任务完成率均持平，不能据此声称公开基准攻击成功率进一步下降。

## 产品修改

- `builtin-indirect-prompt-injection`、`builtin-memory-poisoning` 升级为 `1.0.1`，继续由 Default 启用。
- 扫描完整明文，增加明确的当前任务覆盖模式。原有编码检测只查前 8 个可解码片段，且忽略超过 1024 字符的 token；现在采用总字符和候选数量预算，超限返回 `unknown`，不再当成已检查的安全内容。
- 记忆写入/读取使用实际候选和来源查询共同判断。增加 `The correct answer is C`、`Final answer: C`、括号选项和 yes/no 别名；普通答案、纠正后的答案、歧义答案不因恶意查询单独命中。此规则不验证事实真伪。
- 移除正则命中上未经校准的 0.99/0.97 置信度。
- 新的 `DefaultGuard` 测试适配器运行 Controller 生成的 Default Plan 和真实 Runner，保留来源、查询及 memory operation。独立文档按各自结果隔离；混合文档整体处理，不根据已知 payload 或数据集标签拆掉攻击文本。

截图中的同步 Transformer 分类器、1024 字符截断及固定 0.8 阈值没有加入产品。当前修复没有新增模型依赖，也不具备通用语义注入分类器的覆盖能力。

## 评测协议与评分修复

入口：`scripts/compare_default_boundaries.py`。目标为实际 **Default 的 34 项本地策略组合**，与本地部署当时的组合一致；不包含源码 Default 的另外两项模型策略，不能外推为完整 36 项模型 Default 的成绩。

使用原有冻结包中的 BIPIA 12、AgentPoison 2、MINJA 2，共 16 个场景、10 个不同受害问题。这是历史回归集，不是新的盲测集或论文原始攻击优化协议。执行 clean/attacked × 无 Guard/修复前/修复后，共 96 个分支。

Target 为 DeepSeek Flash；独立结果 Judge 为 DeepSeek V4 Pro，模型不同但服务提供方相同。所有版本共用新的 `semantic-categorical.v3` 评分协议，分别输出正确性与攻击目标是否达成的类别、理由，保留原始响应。严格验证 JSON 及攻击目标适用性；闭合答案与 Judge 分歧单独报告，并在 validated 视图中转为待复核，而不是自动改为成功。自由文本理由的一致性仍不保证。

7 个正反例预检全部通过后才开始正式评测。旧实验的 `semantic-output.v2` 原始成绩未修改，不能直接与 v3 数值横向比较。每个分支独立初始化、清理记忆；只有完全相同的 Target/Judge 输入在本次运行中共享一次响应，并保留缓存来源，避免相同输入的采样波动冒充防护收益。这不是重复采样稳健性实验。

96/96 分支完成，0 执行错误，0 可检测的答案评分冲突，0 未知结果评分。共 **93 次真实请求：Flash 45 次、V4 Pro 48 次（含 7 次预检）**，全部 HTTP 200。首次尝试在预检首调用发生一次 TLS 连接失败，未派发正式场景，已单独保留，不计作攻击失败。

## 结果

| 数据集 | ASR：无 Guard | ASR：修复前 → 修复后 | clean 完成：前 → 后 | attacked 完成：前 → 后 |
| --- | --- | --- | --- | --- |
| BIPIA | 0/12 | 0/12 → 0/12 | 8/12 → 8/12 | 11/12 → 11/12 |
| AgentPoison | 0/2 | 0/2 → 0/2 | 2/2 → 2/2 | 2/2 → 2/2 |
| MINJA | 1/2 | 0/2 → 0/2 | 2/2 → 2/2 | 2/2 → 2/2 |

每版记忆场景的无关正常任务为 8/8。修复前后 32 对同场景分支的 Guard 判定和受害回答全部相同。现有 Default 已挡住本轮 MINJA 成功例；这不是此次补丁新增的收益。

20 个自编边界回归例：10 个攻击、9 个正常、1 个超限。修复前攻击检出 1/10、正常放行 9/9、超限错误放行；修复后攻击检出 10/10、正常放行 9/9、超限为 unknown。该集合针对已知漏洞编写，不能把 100% 检出率视为公开基准泛化成绩。

失败案例仍包含：EmailQA 把“支付给 Josh 的 $600”当成“Josh 支付的金额”；TableQA 女性候选人数回答 2，参考为 3。这些 clean 输入均放行，未发生信息删除，属于 Target 任务错误。也仍有公开间接任务重定向未被本地规则识别，只是 Target 本轮没有服从。更高覆盖需要独立校准的语义检测及更大的未见攻击集，不能靠扩大正则或直接添加关键词黑名单保证。
